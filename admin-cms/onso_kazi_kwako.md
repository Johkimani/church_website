# 🚀 Onso, Kazi Kwako! (Onso, Your Work Starts Here!)


(Here are the clear instructions) on how to get this baby running independently.



###  1: (Setup)

Kwanza, fungua terminal yako kwenye folder la `admin-cms` na ufuate hatua hizi:

1.  **Install Dependencies**:
   
    npm install

2.  **Configuration (.env)**:
    Tengeneza file  `.env` 
    in the 
    ```env
    # URL ya backend yako (badilisha na ile yenye umehost)
    VITE_SERVER_URI=http://localhost:3001/api/v1
    ```
